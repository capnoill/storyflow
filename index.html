How Story Flow works

Everything lives on a free grid — drag anything, anywhere.

  1. Drag any card or section label to reposition it. Positions snap to the grid so things stay tidy.
  2. + Root node creates a new card, placed below everything else on the board by default.
  3. Select a card, then use Add child in the side panel to grow the tree — it's placed just under its parent.
  4. Connect in the toolbar links two existing cards — useful when branches rejoin, like two choices leading to the same next scene.
  5. Edit title, body text, and variables (e.g. neighbour_helpful = TRUE) in the side panel.
  6. + Section label adds a header bar, like an act or chapter title — also freely draggable.
  7. Auto-arrange automatically lays everything out neatly if you want to start fresh — you can keep dragging afterwards.
  8. Export a PNG/SVG image any time, or a JSON file to back up and re-import your work later.
